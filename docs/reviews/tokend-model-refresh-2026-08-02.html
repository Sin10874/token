  1. 先由原 dashboard 变更 owner 提交完整 helper 契约，或明确批准 dashboard active 口径变更；随后补齐其余缺失 API helpers，并让同一 ingestion 全量文件真实执行。否则停止上线。

  3. 只读核验 Supabase migration history、当前 active/previous catalog、preflight 聚合与 catalog hash。

Rollback

  • 激活前：保持旧 active pointer，不删除已安装目录。
  • 激活后：调用既有 paired rollback 恢复 exact previous catalog/run；保留审计和 revisions。
  • CLI：停止分发 2.5.1 / 回退 2.5.0。数据库函数不做破坏性 down migration；如函数需回退，走审阅后的 forward-recovery migration。
