安全上线与回滚

  1. 已合并的 PR #3 将历史同步与 frozen helper 纳入 origin/main@46af772；本 PR 以该 commit 为 base。
  2. 确认本 PR 只剩两笔模型能力提交；不得带入 helper、页面、部署或 npm publish。
  3. 独立临时 PostgreSQL 合同已绿；生产仍先在目标 Supabase schema 上按相同顺序 dry-run/审阅。先建立版本目录与 RPC，再接受新 CLI 流量。
  4. 生产分批调用 tokend_backfill_versioned_model_costs_batch 直到 0，再重建 session costs；观测 unknown/unpriced 数量。
  5. 分配下一 patch 版本，同时更新 package.json 与 release/current-version.json；发布 npm 后由 daemon 自升级。当前 2.4.0 不可重复 publish。
  6. 回滚先恢复 v12 上传 RPC，再执行 v15 rollback 恢复审计过的历史成本；最后重建 session costs。CLI 可回退上一 npm 版本。

生产门：临时 PostgreSQL 合同不等于生产验收。合并后仍须先对目标 Supabase schema 审阅 v15、备份并批准维护窗口；未经批准，禁止 production apply/backfill/npm publish/deploy。
